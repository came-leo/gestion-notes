# Gestionnaire de notes

Une application Python en ligne de commande permettant de gérer des notes

## Fonctionnalités

- Ajoute une note
- Affiche les notes
- Recherche une note
- Modifier une note
- Supprimer une note
- Ajouter une catégorie
- Définir un statut
- Enrégistrer la date de création
- Enrégistrer la date de modification
- Sauvegarder automatiquement une copie des données

## Technologies

- Python
- JSON
- Git

## Utilisation

Lancer le programme avec :

python main.py

```
gestion-notes/
|-- main.py
```
